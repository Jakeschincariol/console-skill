# Runtime log lines triage.py reads

Every line below is printed by PS2Recomp's runtime (checked against the checkout at commit
eb8688b, October 2026). `0x..` values are lowercase hex. Most go to stderr; `run.py` captures
stdout and stderr together. Some depend on build options: `RUNTIME_LOG` lines need
`PS2X_ENABLE_RUNTIME_LOGS` (ON by default) and the IOP trace needs `PS2X_ENABLE_IOP_RPC_TRACE`
(ON by default).

Lines run.py also looks at: `[pad-replay] loaded N lines from <file>` (the replay is active) and
`[pad-replay] script finished at frame N`. Useful `--expect` targets: `Using argv boot path` and
`ELF file loaded successfully. Entry point: 0x..` (boot reached `loadELF`), plus any line your game
prints through `printf` or `scePrintf` at a milestone.

The file is a guess from the name: `/console-backend` checks `ps2_call_list.h` for the real handler.

## Ranking

Tier first (0 = stopped the run, then missing functions, stubs, syscalls, IOP, file I/O, override
problems, build options, test input), then the earliest first occurrence across the logs given,
then the highest count. The earliest blocker usually hides the ones after it, so fix from the top.
